## 詳細な説明（最大4000文字）

```
■ FXトレーダーのための、エリオット波動 自動分析アプリ

「FXエリオット波動チェッカー」は、為替チャートからエリオット波動を自動検出し、
現在の波カウントとトレード方向のシグナルをひと目で表示する、無料の分析ツールです。

エリオット波動理論は、相場が「5波の推進＋3波の修正」というリズムで動くという考え方。
このアプリは ZigZag アルゴリズムでピボット（高値・安値）を抽出し、
推進波（1〜5）と修正波（A〜C）を自動で識別。
さらに 23.6%・38.2%・50%・61.8%・78.6% のフィボナッチ・リトレースメントも
チャート上に重ねて描画します。

■ こんな方におすすめ

・チャートの波の数え方が分からないトレーダー
・押し目買い・戻り売りのタイミングを精度よく狙いたい方
・エリオット波動を学習中の方
・ボラティリティの高い相場で、客観的な視点が欲しい方

■ 主な機能

✓ 主要7通貨ペアに対応
  USD/JPY、EUR/JPY、GBP/JPY、AUD/JPY、EUR/USD、GBP/USD、AUD/USD

✓ 8種類の時間足
  1分・5分・15分・30分・1時間・4時間・日足・週足

✓ エリオット波動の自動検出
  推進波（1-2-3-4-5）と修正波（A-B-C）を色分けして可視化

✓ Buy / Sell / Wait シグナル
  現在の波カウントから次の値動きを推定し、トレード方向を提示

✓ フィボナッチ・リトレースメント
  押し目・戻りの目安となる主要レベルを自動描画

✓ ZigZag 感度の調整
  小さな波を拾うか大きな波だけを見るか、好みに合わせてカスタマイズ

✓ デモモードを標準搭載
  APIキー登録なしですぐに動作確認できます

■ 使い方

1. アプリを起動
2. 通貨ペアと時間足を選択
3. チャートに自動で波カウントが描画される
4. Buy / Sell / Wait シグナルでトレード判断の参考に

本格的にリアルタイム分析を行いたい方は、Alpha Vantage（無料）の API キーを
取得して設定画面から登録してください。

保証するものではありません。
```
