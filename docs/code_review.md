## 🟡 中程度（時間あれば対応）

### 1. `requestNonPersonalizedAdsOnly: true` を固定している
**場所**: `src/screens/HomeScreen.tsx:173`

現状すべてのユーザーに「非パーソナライズ広告のみ」を返している。これは GDPR/CCPA 対応として安全側に振っているが、収益効率は下がる。

**対応案：**
- MVP リリースはこのまま（Google AdMob のポリシー違反リスクなし）
- 将来 UMP（User Messaging Platform）SDK を入れて同意取得 → 同意ユーザーには通常広告を表示

### 2. `useEffect(() => { loadData(); }, [])` の依存配列警告
**場所**: `src/screens/HomeScreen.tsx:41-43`

`loadData` が依存配列に入っていないため、ESLint react-hooks/exhaustive-deps 警告が出る可能性。zustand の getter 経由で参照は安定なので実害はないが、将来的に hot-reload 時の挙動に影響する可能性。

**対応案：**
- そのまま放置（実害なし）、または
- `// eslint-disable-next-line react-hooks/exhaustive-deps` コメントで明示

### 3. デモモードでのデータ生成が乱数依存
**場所**: `src/services/fxApi.ts` の `generateDemoCandles`

毎回ランダムな波形が生成されるため、スクリーンショット等で再現性が必要な場面で苦労する可能性。シード固定オプションを足すと便利。

## 🟢 軽微（任意）

### 4. 日付フォーマットがロケール依存
**場所**: `src/screens/HomeScreen.tsx:51`

`d.toLocaleTimeString('ja-JP', ...)` で日本ロケール固定。海外ユーザーが使った場合の表示は問題ないが、もし英語版を出すなら要対応。

### 5. ドキュメントが README に存在しない
リポジトリが public になったので、README 追加推奨（→ `README.md` 別途作成）。

### 6. テストコードなし
ユニットテスト（特に `algorithms/elliottWave.ts` のロジック）があると将来の変更に強い。MVP段階では優先度低。

### 7. エラーメッセージが日本語固定
`src/store/useStore.ts:106` の "データの取得に失敗しました。" が日本語ハードコード。
i18n を入れる予定なら対応必要だが、現状は問題なし。
