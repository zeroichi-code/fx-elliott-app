## バージョニング方針（参考）

セマンティックバージョニング（Semantic Versioning）に準拠：

- **メジャー（X.0.0）**：互換性のない大規模な変更
- **マイナー（X.Y.0）**：後方互換性のある機能追加
- **パッチ（X.Y.Z）**：後方互換性のあるバグ修正

例：
- `1.0.0` 初回
- `1.0.1` バグ修正
- `1.1.0` 新通貨ペア追加
- `2.0.0` UI全面刷新

`app.json` の `version` と `android.versionCode` を更新してから新ビルド。
